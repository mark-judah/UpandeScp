# Scouting avocado

`/scp_app#/avocado/…`

Avocado is a working crop in the app, but a **scouting-and-reporting** one. It
does not carry the spray-planning chain.

## Where you scout

```
Block  →  Row  →  Tree
```

Different from roses, and the difference is real rather than cosmetic. An
avocado entry names a **block** and a **tree**, not a greenhouse, bed and zone.
It is the same idea — a place you can point at — at the scale of an orchard.

## What you can record

**12 pests**

Caterpillars · Coconut Bug · FCM · Fruit fly (Bactocera) · Fruit fly (Ceratitis) ·
Leaf Rollers · Loopers · Mealybugs · Mosquito Bugs · Scale Insects · Stinkbug ·
Unidentified Insects

**4 diseases**

Anthracnose · Avocado Scab · Cercospora Spot · Phytophthora Root Rot

Two pests overlap with roses — **FCM** (false codling moth), **Mealybugs** and
**Scale Insects** — but their thresholds are set separately for avocado, so the
same count can mean different things on the two crops.

## The views you have

| Section | Views |
|---|---|
| Overview | Dashboards, Trends |
| Scouting | Scouting Map, Observations, Traps |
| Crop Protection | **Jobsheet** |
| Reports | Reports |

### Jobsheet

Where roses have "Heatmaps", avocado has **Jobsheet** — the same underlying
view, named for what it is used for. From the map you prescribe a block to be
sprayed, and that is the avocado equivalent of a spray plan.

It is a jobsheet, not an approval chain. There is no Application Plan, no
Approvals queue, no Tank Mixes and no Postponements for avocado.

### Weekly block report

Avocado has a weekly per-block report covering pest and disease pressure across
the orchard, found under **Reports**.

## What avocado does not have

**Spraying, Application Plan, Chemical Stock, Chemical Loaning, Procurement,
Approvals, Postponements, Settings, Historical, Tank Mixes.**

If you need a full spray plan with approval on avocado, it does not exist yet.
Prescribe from the Jobsheet.
