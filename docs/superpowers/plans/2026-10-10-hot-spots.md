# Hot Spots Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tell the field team when one section of a greenhouse or block (one cell of piece 2's 3 × 3 grid) is clearly worse than the house as a whole. A **Hot spot** is raised when the section's band is higher than the house's band, at least Moderate, and the section has ≥ 5 scouted stations. It is "stay alert" only, with no spray advisory. It goes to the Alarming audience in-app and in the 17:00 digest, and shows on the Overview alerts card and as a ring on the greenhouse modal's grid. The same piece fixes the carried 3a minor: the sweep reopens a dead-plan Converted alert only when the key's latest finding still has an action, and resolves it otherwise.

**Architecture:** The pure rule lives in `common/threshold_bands.py` (`section_readings` / `hotspots`, `band_escalates`, `section_label`, `HOTSPOT_MIN_N`). `scouting/thresholds_check.evaluate` already holds each house figure's `sections`. Per banded key it now adds one hot-spot finding per section with a figure, and needs no extra query. The finding carries action `Hot spot` when the section meets H2 and `None` otherwise, so a cooled section resolves its hot spot. **Scouting Alert** gains `alert_type` / `section_row` / `section_col` / `section_label` and `notified_band`. The name stays the hashed key: House keys hash exactly as before, and hot-spot keys append type + row + col. Every key-based SQL statement includes the three new key columns, so house and hot-spot alerts never resolve or carry each other. `upsert` escalates a hot spot by band (Moderate → High) and a house alert by action. `open_alerts`, the digest and `_gh_detail` surface hot spots. The creator never sees them.

**Tech Stack:** Frappe v16 / Python 3.14, MariaDB; React 19 + TypeScript + Vite + vitest (jsdom, @testing-library/react) in `frontend/`.

**Spec:** `docs/superpowers/specs/2026-10-10-hot-spots-design.md` (binding). Builds on `docs/superpowers/plans/2026-10-10-thresholds-and-actions.md` (3a). All line numbers below are verified against HEAD `c8a86de`.

## Review Focus

The five failure modes most likely to slip past the tests, each with the test that pins it:

1. **House and hot-spot alerts cross-resolving or cross-carrying.** They share warehouse/kind/observation/stage/week. If any key-based SQL forgets `alert_type`/`section_row`/`section_col`, then a clean house reading resolves a live hot spot, a cooled section resolves the house's Spray advised, or a hot spot's `notified_band` silences next week's house alert. → Task 2 `test_resolve_touches_only_its_own_type_and_section`, `test_previous_live_never_crosses_types`. Task 4 `test_a_clean_house_reading_never_resolves_a_hot_spot`, `test_a_cooled_section_never_resolves_the_house_alert`.
2. **Existing House alert names changing.** If the key format changes for House rows, the next hourly run inserts a duplicate of every live alert and re-notifies everyone. → Task 2 `test_house_names_hash_exactly_as_before` (golden literal from HEAD's formula), `test_a_house_doc_without_type_keeps_its_old_name`, `test_old_rows_read_as_house_with_no_section`. Task 4 `test_the_house_alert_written_by_the_check_keeps_its_old_name`.
3. **A section the house did not scout this week.** A section with fewer than 3 stations has `pct`/`avg` None. It must neither raise nor resolve, and a thin later reading (n < 5) must not clear last week's hot spot. → Task 1 `test_a_section_without_a_figure_is_skipped`. Task 4 `test_unscouted_sections_neither_raise_nor_resolve`, `test_a_thin_section_reading_does_not_resolve_last_weeks_hot_spot`.
4. **Avocado blocks: rows and trees, not beds and zones.** The section label must say "rows" on a Block crop, and the figure must come from Orchard Trees. → Task 1 `test_section_label_speaks_beds_or_rows`. Task 4 `test_an_avocado_block_names_rows`.
5. **Notification double-count when the house and a hot spot raise together.** Each alert notifies its audience exactly once. A rerun is silent. The approver (who gets the house's Spray advised but not Alarming) is never told about a hot spot. → Task 4 `test_house_and_hot_spot_raised_together_notify_once_each`. Task 5 `test_a_hot_spot_reaches_the_digest_with_its_label` (the digest lists both once).

The carried 3a minor (sweep reopening a dead-plan alert whose latest finding has no action) is pinned by Task 3 `test_the_sweep_resolves_a_dead_plan_alert_whose_latest_finding_has_no_action` and `test_a_direct_sweep_checks_the_latest_finding_too`.

```python


# ── hot spots (spec 2026-10-10-hot-spots, H1–H5) ──────────────────────────

HOUSE = "House"
HOT_SPOT = "Hot spot"
ALERT_TYPES = (HOUSE, HOT_SPOT)
#: H2: a section needs at least this many scouted stations to be a hot spot.
HOTSPOT_MIN_N = 5
#: A section's reliability is Fair from HOTSPOT_MIN_N stations, Good from this.
HOTSPOT_GOOD_N = 10
#: Band order for comparing a section with its house ("" = judged, below Low).
BAND_RANK = {"": 0, "low": 1, "moderate": 2, "high": 3}
#: Sort order across both alert types: a hot spot sits with Alarming. Not an
#: escalation ladder — a hot spot escalates by band (``band_escalates``).
ALERT_RANK = {**ACTION_RANK, HOT_SPOT: ACTION_RANK[ALARMING]}
_STORED_BAND_RANK = {"Moderate": 1, "High": 2}
_ROW_WORDS = ("first", "middle", "last")
_COL_WORDS = ("front", "middle", "back")


def section_value(section, measure):
    """A section's figure in the row's measure: ``avg`` (count per scouted
    station) for a Count, ``pct`` for a Percentage. None below 3 stations."""
    return section.get("avg") if measure == COUNT else section.get("pct")


def section_reliability(n) -> str:
    """Spec §3: Good if n ≥ 10, Fair if n ≥ 5, else Low."""
    n = int(n or 0)
    if n >= HOTSPOT_GOOD_N:
        return "Good"
    if n >= HOTSPOT_MIN_N:
        return "Fair"
    return "Low"


def section_readings(house_value, sections, bands, measure) -> list:
    """Every section with a figure, judged against its house (H2):
    ``{"row", "col", "value", "scouted", "band", "reliability", "hot"}``.

    ``hot`` when the section's band is at least Moderate, higher than the
    house's band, and the section has ≥ HOTSPOT_MIN_N scouted stations.
    ``bands`` is a band spec (``{"low", "mod", "high"}``, as ``band_spec``
    returns). Nothing when the house has no figure or the bands are unset or
    misordered; a section without a figure (< 3 stations) is skipped — it is
    no reading, so it neither raises nor resolves."""
    low, mod, high = bands.get("low"), bands.get("mod"), bands.get("high")
    house_band = band_of(house_value, low, mod, high)
    if house_band is None:
        return []
    house_rank = BAND_RANK.get(house_band, 0)
    out = []
    for s in sections or ():
        value = section_value(s, measure)
        if value is None:
            continue
        band = band_of(value, low, mod, high) or ""
        rank = BAND_RANK.get(band, 0)
        n = int(s.get("scouted") or 0)
        out.append({
            "row": s["row"], "col": s["col"], "value": value, "scouted": n, "band": band,
            "reliability": section_reliability(n),
            "hot": n >= HOTSPOT_MIN_N and rank >= BAND_RANK["moderate"] and rank > house_rank,
        })
    return out


def hotspots(house_value, sections, bands, measure) -> list:
    """The sections meeting H2 (see ``section_readings``)."""
    return [r for r in section_readings(house_value, sections, bands, measure) if r["hot"]]


def band_escalates(previous, new) -> bool:
    """H5: a hot spot is announced again only when its section's band rises
    (stored labels ``Moderate`` → ``High``)."""
    if new not in _STORED_BAND_RANK:
        return False
    return _STORED_BAND_RANK[new] > _STORED_BAND_RANK.get(previous or "", 0)


def section_unit(station) -> str:
    """``row`` for a crop scouted on trees (avocado blocks), else ``bed``."""
    return "row" if station == "tree" else "bed"

    """``first beds · front`` / ``last rows · back`` — rows of the 3 × 3 grid are

def sweep(crop, today=None, latest=None, actionable=None) -> int:
    """Resolve the crop's Open / Acknowledged alerts that no check will ever
    touch again: their key is no longer banded, or their ISO week ended before
    the evaluation window (a house no longer scouted). Converted alerts are
    left to their plan, unless that plan is dead: such an alert is reopened
    only when its week is still its house's latest week (``latest``: warehouse
    → ISO week) AND its key's latest finding still has an action
    (``actionable``: ``finding_key``s) — else resolved, because a breach that
    has since cleared is nobody's to plan. Both come from this run's findings;
    either missing is derived from ``evaluate``. Returns how many were
    resolved."""
    crop = crop_catalog.canonical(crop) or crop
    if not crop:
        return 0
    today = today or now_eat().date()
    window_start = today - timedelta(days=EVAL_WINDOW_DAYS - 1)
    banded = {(KIND_LABEL[k], obs, stage or "") for k, obs, stage in _common.load_thresholds(crop)}
    rows = frappe.get_all(
        DOCTYPE, filters={"crop": crop, "status": ["in", list(OPEN_STATES)]},
        fields=["name", "kind", "observation", "stage", "iso_week"], limit_page_length=0,
    )
    stale = [
        r.name for r in rows
        if (r.kind, r.observation, r.stage or "") not in banded or _week_ended(r.iso_week, window_start)
    ]
    for name in stale:
        frappe.db.set_value(DOCTYPE, name, "status", "Resolved")
    if latest is None or actionable is None:
        findings = evaluate(crop, today)
        if latest is None:
            latest = {f["warehouse"]: f["iso_week"] for f in findings}
        if actionable is None:
            actionable = {finding_key(f) for f in findings if f["action"]}
    now = now_eat()
    orphans = frappe.get_all(
        DOCTYPE, filters={"crop": crop, "status": "Converted to plan"},
        fields=["name", "warehouse", "kind", "observation", "stage", "iso_week", "work_order",
                "alert_type", "section_row", "section_col"],
        limit_page_length=0,
    )
    for r in orphans:
        if not plan_is_dead(r.work_order):
            continue
        if latest.get(r.warehouse) == r.iso_week and _row_key(r) in actionable:
            frappe.db.set_value(DOCTYPE, r.name, {
                "status": "Open", "work_order": None,
                "raised_on": now.date(), "raised_at": eat_stamp(now),
            })
        else:
            frappe.db.set_value(DOCTYPE, r.name, "status", "Resolved")
            stale.append(r.name)
    return len(stale)


def check_crop(crop, today=None) -> dict:
    findings = evaluate(crop, today)
    alerts = [n for n in (upsert(f) for f in findings) if n]
    latest = {f["warehouse"]: f["iso_week"] for f in findings}
    actionable = {finding_key(f) for f in findings if f["action"]}
    return {"findings": len(findings), "alerts": len(alerts), "swept": sweep(crop, today, latest, actionable)}

def evaluate(crop, today=None) -> list:
    """Findings for every house scouted in its latest ISO week of the window ×
    every banded key: the house finding (``alert_type`` House), then one
    hot-spot finding per section with a figure (``_section_findings``). A
    finding with ``action`` None resolves rather than raises: a house below
    Moderate ("" or "low"), or a section that does not meet hot-spots H2."""
    crop = crop_catalog.canonical(crop)
    keys = sorted(_common.load_thresholds(crop)) if crop else []
    if not keys:
        return []
    today = today or now_eat().date()
    from_date = (today - timedelta(days=EVAL_WINDOW_DAYS - 1)).isoformat()
    kinds = tuple(sorted({kind for kind, _obs, _stage in keys}))
    weeks = R.StationWeeks.load(from_date, today.isoformat(), crop, None, kinds=kinds, lookback_days=0)
    station = _common.station_word(crop)
    unit_word = B.section_unit(station)
    out = []
    for wh in weeks.warehouses():
        week, previous = weeks.latest_pair(wh)
        if not week:
            continue
        for kind, obs, stage in keys:
            spec = _common.band_spec(crop, kind, obs, stage)
            if not spec:
                continue
            fig, value = _figure(weeks, wh, week, kind, obs, stage, spec)
            if value is None:
                continue
            band = B.band_of(value, spec["low"], spec["mod"], spec["high"])
            house = {
                "crop": crop, "warehouse": wh, "kind": kind, "observation": obs,
                "stage": stage, "iso_week": week, "previous_week": previous,
                "alert_type": B.HOUSE, "section_row": -1, "section_col": -1, "section_label": "",
                "measure": spec["measure"],
                "unit": B.unit_label(spec["measure"], station), "value": value,
                "margin": fig.get("margin"), "reliability": fig.get("reliability") or "Low",
                "sections_scouted": fig.get("sections_scouted") or 0,
                "sections_total": fig.get("sections_total") or P.SECTIONS,
                "band": band, "action": B.action_for(band, fig.get("reliability")),
            }
            out.append(house)
            out.extend(_section_findings(house, fig, spec, unit_word))
    return out


def _section_findings(house, fig, spec, unit_word) -> list:
    """Hot-spots H2 for each section of the house's figure, in the row's
    measure (section ``pct`` for a Percentage, ``avg`` for a Count): no extra
    query. A section that meets H2 raises ``Hot spot``. Every other section
    with a figure is a clear reading (action None) that resolves its hot spot:
    this week's always, older weeks' only when the section is Fair/Good
    (n ≥ 5) or its week is over (3a's thin-sample rule, H6). A section without
    a figure (< 3 stations scouted) yields nothing."""
    out = []
    for r in B.section_readings(house["value"], fig.get("sections"), spec, spec["measure"]):
        out.append({
            **house,
            "alert_type": B.HOT_SPOT, "section_row": r["row"], "section_col": r["col"],
            "section_label": B.section_label(r["row"], r["col"], unit_word),
            "house_value": house["value"], "value": r["value"], "margin": None,
            "reliability": r["reliability"], "sections_scouted": r["scouted"], "sections_total": 1,
            "band": r["band"], "action": B.HOT_SPOT if r["hot"] else None,
        })
    return out

def upsert(finding, now=None, _retry=True):
    """Write one finding. Returns the alert's name, or None for a finding with
    no action (a house below Moderate, a section no longer meeting H2), which
    resolves the key's open alerts up to its week. A house alert escalates by
    its action (D5); a hot spot by its section's band, Moderate → High
    (hot-spots H5). The two never share a key (``_key_params``)."""
    now = now or now_eat()
    params = _key_params(finding)
    hot = params["type"] == B.HOT_SPOT
    action = finding["action"]
    if not action:
        _resolve(params, include_week=True, older=_clean_may_supersede(finding, now))
        return None

    name = _name_for(params)
    band = B.BAND_LABEL[finding["band"]]
    fields = {
        # ``margin`` is a NOT NULL Float: a clustered figure (m < 2, margin
        # None) or a hot spot (one section, no margin) is stored as 0 and read
        # back as None by ``_margin``.
        "measure": finding["measure"], "value": finding["value"], "margin": finding["margin"] or 0,
        "reliability": finding["reliability"], "sections_scouted": finding["sections_scouted"],
        "sections_total": finding["sections_total"], "band": band, "action": action,
    }
    level, level_field = (band, "notified_band") if hot else (action, "notified_action")
    existing = _existing(name, latest=not _retry)
    reopened = False
    if existing and existing.status == "Converted to plan":
        if not plan_is_dead(existing.work_order):
            # A live curative plan owns this alert: never overwrite or re-notify it.
            return name
        # Its plan was deleted, cancelled, stopped (auto-cancel / rejection) or
        # closed: the breach is nobody's again. Reopen it; escalation rules
        # below decide whether anyone is told.
        frappe.db.set_value(DOCTYPE, name, {"status": "Open", "work_order": None})
        existing.status = "Open"
        reopened = True
    if existing:
        frappe.db.set_value(DOCTYPE, name, fields)
        already, status = existing.get(level_field), existing.status
    else:
        previous = _previous_live(params, finding.get("previous_week"))
        doc = frappe.get_doc({
            "doctype": DOCTYPE, "crop": finding["crop"],
            "farm": frappe.db.get_value("Warehouse", params["wh"], "custom_farm"),
            "warehouse": params["wh"], "kind": params["kind"], "observation": params["obs"],
            "stage": params["stage"], "iso_week": params["week"],
            "alert_type": params["type"], "section_row": params["row"], "section_col": params["col"],
            "section_label": finding.get("section_label") or "",
            **fields,
            "status": "Open", "raised_on": now.date(), "raised_at": eat_stamp(now),
            # Carried across weeks: the same action (house) or band (hot spot)
            # again is not news (D5, H5).
            level_field: previous.get(level_field) if previous else None,
        })
        try:
            doc.insert(ignore_permissions=True)
        except frappe.DuplicateEntryError:
            # Another run inserted this key first and owns its notification:
            # re-read the winner (locking read) and carry on from its state.
            if not _retry:
                return name
            return upsert(finding, now, _retry=False)
        already, status = doc.get(level_field), "Open"
        existing = frappe._dict(notified="")

    updates = {}
    if reopened:
        # A live breach lost its plan: land in the next digest.
        updates.update(raised_on=now.date(), raised_at=eat_stamp(now))
    if status == "Resolved":
        # This week's figure dropped out and came back.
        updates.update(status="Open", raised_on=now.date(), raised_at=eat_stamp(now))
    escalated = B.band_escalates(already, level) if hot else B.escalates(already, level)
    if escalated:
        updates.update({level_field: level, "raised_on": now.date(), "raised_at": eat_stamp(now)})
        if status == "Acknowledged":
            updates["status"] = "Open"
        sent = _notify(name, finding, action, PLAN_GONE if reopened else "")
        if sent:
            told = set(filter(None, (existing.notified or "").split("\n"))) | set(sent)
            updates["notified"] = "\n".join(sorted(told))
    elif reopened:
        # Same action as already announced, but the plan is gone: say so.
        sent = _notify(name, finding, action, PLAN_GONE)
        if sent:
            told = set(filter(None, (existing.notified or "").split("\n"))) | set(sent)
            updates["notified"] = "\n".join(sorted(told))
    if updates:
        frappe.db.set_value(DOCTYPE, name, updates)
    _resolve(params, include_week=False)   # a newer week supersedes older alerts
    return name
```
