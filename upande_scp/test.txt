1. Core Design System (Frappe v16 Desk)
Design philosophy

Minimal ERP UI

Neutral greys + accent color

High readability

Bootstrap-inspired layout

CSS variables for dynamic themes

The styling is mainly controlled using SCSS variables compiled into CSS and runtime CSS variables (--variable).

7. Dark Mode Theme

Frappe v16 includes dark mode variables.

Example:

[data-theme="dark"] {

--bg-color: #161a1f
--fg-color: #1c2126
--text-color: #90949f
--heading-color: #b2b7c5

}

This swaps the background and text colors dynamically.
